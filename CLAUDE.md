# NativeForge: notes for AI assistants

Android IDE (Kotlin + Compose) that compiles and runs C/C++ **on the device**
with clang from Termux packages, runs console or graphical programs, and exports
them as APK/AAB. GPL-3.0-or-later, aimed at F-Droid. Package
`io.github.deuzivanviana.nativeforge`, code namespace `io.nativeforge.*`.

Read only what the task needs. Deeper docs:
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) (design, extension points),
[packages/README.md](packages/README.md) (library index, rebuilding libs),
[docs/FDROID.md](docs/FDROID.md), [docs/SECURITY.md](docs/SECURITY.md),
[docs/ROADMAP.md](docs/ROADMAP.md) (per-version changes).

## Module map

| Module | Kind | Holds |
| --- | --- | --- |
| `app` | Android app | screens + view models (`ui/home`, `ui/workspace`, `ui/export`, `ui/packages`, `ui/settings`), wiring in `di/AppContainer.kt`, `run/ProgramRunner.kt`, `intel/CodeIntelService.kt`, `signing/`, `storage/DeviceFolders.kt` |
| `core/common` | JVM | `Outcome<T>`/`NfError`, process runner, dispatchers, `SafeFiles` |
| `core/project` | JVM | `ProjectConfig` (`nativeforge.json`), repository, detector, search, **templates/examples** |
| `core/toolchain` | JVM | ABI, on-device layout, `ClangToolchain`, `PrefixRelocator`, `TermuxShellPatch` |
| `core/build` | JVM | `BuildSystem`s (SINGLE, CMAKE, MAKE, NINJA), `BuildExecutor`, diagnostics, compiler shims |
| `core/packages` | JVM | package sources (Termux APT, JSON index), resolver, installer |
| `core/export` | JVM | AXML/proto manifest patchers, `ApkExporter`, apksig signing, keystores |
| `core/vcs` | JVM | JGit wrapper `GitClient` |
| `core/lsp`, `core/codeintel` | JVM | LSP client; clangd session, compile DB, clang-format |
| `core/assets` | JVM | OBJ/STL/PLY/glTF/TGA parsers |
| `core/ui` | Android | Compose theme, shared components |
| `feature/editor` | Android | Sora editor + TextMate (`src/main/assets/textmate/`) |
| `feature/terminal` | Android | `ConsoleActivity` (Termux terminal-view, PTY) |
| `feature/runner` | Android | program hosts (NativeActivity, SDL3, SDL2) in `:runner` process; native shim in `src/main/cpp`; SDL Java glue in `java/org/libsdl/{app,sdl2}` (vendored, don't edit) |
| `feature/assets` | Android | asset viewer (images, audio, GLES model preview) |
| `runtime-template` | Android app | host app for exported programs; built at IDE build time and embedded as `assets/runtime/template.apk` |
| `build-logic` | Gradle | convention plugins; SDK levels in `NativeForgeConfig.kt` |
| `packages/` | scripts | `build-android-libs.sh` (rebuilds bundled libs with the NDK), `sources.sha256`, LVGL glue (`lv_nativeforge.*`) |

Rule: `core/*` (except `core/ui`) has **no Android dependency**; put logic there
and test it with JUnit. Only `app` picks implementations (`AppContainer`).

## Where things live

* Templates and examples: `core/project/.../template/ProjectTemplates.kt`
  (list, order = UI order); short sources inline in `TemplateSources.kt`, larger
  ones as files in `core/project/src/main/resources/io/nativeforge/core/project/templates/<id>/`
  read with `TemplateResources.read("<id>/main.c")`.
* Bundled Android libraries (~23 MB of `.tar.xz` per ABI + `index.json`):
  `app/src/main/assets/packages/`. Generated by `packages/build-android-libs.sh`;
  never hand-edit archives. `index.json` is large (42 KB): grep it.
* Navigation: `app/.../ui/navigation/NativeForgeNavHost.kt` (`Routes`).
* Runtime host per `RuntimeKind`: `feature/runner/.../ProgramLauncher.hostFor()`.
* Store listing and changelogs: `fastlane/metadata/android/{en-US,pt-BR}/`.

Large files, read by range or grep: `TemplateSources.kt` (~1000 lines),
`WorkspaceViewModel.kt` (~970), `WorkspaceScreen.kt`, `packages/build-android-libs.sh` (~620).

## Build and test

Requirements: JDK 17, Android SDK 35, NDK `27.2.12479018` (CMake 3.22.1 for libs).

```bash
./gradlew test                     # all JVM unit tests (core modules)
./gradlew :core:build:test         # one module; prefer this while iterating
./gradlew :app:assembleDebug       # IDE APK; also builds runtime-template and the NDK shim (slow)
```

* A fresh cloud container has no Android SDK, and Maven Central may answer 429,
  so Gradle may not run there. Don't spend time on full APK builds: CI
  (`.github/workflows/android.yml`) runs `test` + `assembleRelease` on every PR and push,
  signs the APK with the release key (`.github/scripts/sign-apk.sh`) and uploads it.
* Gradle has configuration cache, build cache and parallel on (`gradle.properties`).
* Tests use `kotlin.test` + JUnit 4 + `kotlinx-coroutines-test`, next to the
  sources in `src/test/kotlin`. Fakes: `core/build/src/test/.../FakeToolchain.kt`.

## Conventions

* Code, comments and docs in English. The owner writes in Portuguese; store
  text exists in `en-US` and `pt-BR`.
* Errors across modules: `Outcome<T>` with typed `NfError`. Long work: cold
  `Flow`s of events. Blocking I/O on injected `DispatcherProvider`.
* Module build files only declare namespace and dependencies; shared Gradle
  setup goes in `build-logic`. Versions in `gradle/libs.versions.toml`.
* Every logic change in `core/*` comes with a JVM test.
* `.gitignore` ignores `build/` only per module: `core/build` is a source module.

## Constraints (don't break these)

* **targetSdk 28 for the IDE** is deliberate (exec of downloaded binaries; legacy
  storage). Exported apps target 35. Don't "upgrade" it.
* **F-Droid**: free dependencies only (Maven Central, Google, JitPack for Termux
  terminal). No Play Services, analytics, ads or crash reporting. Toolchain
  downloads stay opt-in behind `ToolchainConsentDialog`. Prebuilt archives must
  be reproducible from pinned sources (`packages/sources.sha256`); new sources
  need a checksum.
* Security: package archives need a SHA-256 and HTTPS; Git is HTTPS-only, no
  hooks/symlinks/submodules. See `docs/SECURITY.md` before touching these.
* Never commit keystores, `*.jks` or secrets. Release signing happens in CI
  from `RELEASE_*` secrets.
* SDL Java glue must match the bundled SDL version (see `packages/README.md`).

## Common tasks

| Task | Touch |
| --- | --- |
| New template/example | `ProjectTemplates.all` + sources (inline or `resources/.../templates/<id>/`); C and C++ variants when the libs allow; packages by name from `index.json` |
| New/updated bundled library | `packages/build-android-libs.sh`, `packages/sources.sha256`, regenerated `app/src/main/assets/packages/`, `THIRD_PARTY_NOTICES.md`; CI `libs-from-source.yml` checks it |
| New build system / runtime / package source | extension-point table in `docs/ARCHITECTURE.md` |
| New screen | Composable + ViewModel, `Routes`, `di/ViewModelFactories.kt` |
| Release | bump `versionCode`/`versionName` in `app/build.gradle.kts`; add `fastlane/metadata/android/{en-US,pt-BR}/changelogs/<versionCode>.txt` (≤500 chars); add a section to `docs/ROADMAP.md`; update the status line in `README.md`; after merge push tag `vX.Y.Z` (`release.yml` builds, signs, publishes) |
