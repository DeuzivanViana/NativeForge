# Screenshots

F-Droid shows the PNG or JPEG files in `metadata/android/<locale>/images/phoneScreenshots/`
in name order (`1.png`, `2.png`, ...). They are still to be taken on a device:

1. Home screen with project cards
2. Editor with clangd completion open
3. Live diagnostics in the editor and the Problems panel
4. Split editor with a physical keyboard (command palette open)
5. A raylib or SDL3 program running full screen
6. The asset viewer showing a 3D model
7. The export screen

Use portrait phone captures (for example 1080×2400) without personal data.
`tenInchScreenshots/` can hold tablet captures of the split editor.
